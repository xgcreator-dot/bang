# 标讯通 · 招投标信息采集与管理平台

本仓库包含一个可在本机运行的招投标信息管理系统，包含公开信息检索、会员管理、系统维护和大数据采集四个工作平台。

## 本机运行

1. 安装 Python 3.10 或更新版本。
2. 双击 `outputs/启动本地演示.bat`，或在 `outputs` 目录运行 `python server.py`。
3. 在浏览器打开 `http://127.0.0.1:8765/`。

会员演示账号：手机号 `13800000000`，密码 `BidDemo123!`。会员登录由本机 SQLite 数据库校验。

数据库默认写入 `work/bid_suite.sqlite3`，该运行数据不会提交到 Git。

## 当前能力

- 公告搜索、筛选、详情展示与会员原文链接访问。
- 会员新增、状态与等级管理、导出及登录审计。
- 来源平台登记、规则核验、RSS / Atom 来源配置和手动或周期采集。
- 公告信息去重入库、本机运行状态和操作审计查看。
- 手机浏览器适配；同一局域网手机可访问公开信息页面，管理接口限制为部署电脑本机。

## 数据接入范围

当前采集器支持标准 RSS / Atom Feed。非标准站点需要单独开发并核验适配器；添加来源前应确认公开来源的访问规则和允许频率。首次启动创建的公告与来源是演示数据，不代表真实实时招标信息。

这是本机运行的开发版本，尚未包含生产环境所需的 HTTPS、管理员账号与角色权限、外部部署配置及全站点采集适配。

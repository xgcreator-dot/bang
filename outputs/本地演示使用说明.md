# 标讯通本机可运行版

## 启动

1. 电脑安装 Python 3.10 或更新版本。
2. 双击 `启动本地演示.bat`，服务启动后在浏览器打开 `http://127.0.0.1:8765`。
3. 首页进入四个平台；招标公告、会员、来源、采集任务和审计记录保存到 `work/bid_suite.sqlite3`，重启后保留。页面适配手机窄屏。
4. 可用内置会员账号登录公开信息平台：手机号 `13800000000`，密码 `BidDemo123!`。这是初始演示账号；会员管理页可创建自己的账号。管理接口只允许部署电脑本机调用。
5. 手机与电脑接入同一 Wi-Fi 后，在手机浏览器打开 `http://电脑的局域网IPv4地址:8765`。公告检索与会员登录可从手机访问；会员名单、来源配置、任务执行和系统维护仍限本机。

演示数据库自动创建在项目的 `work/bid_suite.sqlite3`。平台收集库与项目公告库分开存储；平台库登记平台名称、官网、地区、信息类别、接入方式、核验状态和关联连接器。停止服务再重新启动后，已新增的平台、会员、来源、采集任务和公告仍会保留。

## 采集与入库

- 打开“大数据采集管理”，平台收集库已预置国家招标投标公共服务平台、中国政府采购网、全国公共资源交易平台及其数据服务等候核验平台，也可登记新平台。
- 核对来源访问规则后，在平台库中点击“核验并启用”；新增 RSS / Atom 采集任务时，将连接器绑定到对应平台。
- Feed 地址必须使用 HTTPS；系统只接受登记来源同一域名下的公告详情链接。
- 点击任务“运行”后，系统读取 Feed 中的公告条目，将公告标题、来源详情 URL、来源公告标识和发布时间写入 SQLite。设置每 30 分钟、每小时或每日后，本地服务运行期间会按设置自动调度；手动任务不会自动运行。
- 再次运行时按来源公告标识更新已有记录，避免重复创建；招标信息平台会从数据库读取公告并周期刷新。
- 每条记录使用自己的详情 URL。没有准确详情 URL 的演示数据会显示“原文链接暂不可用”，不会跳到来源首页。

## 当前版本范围

- 首次启动会创建少量演示公告、会员和待核验来源。演示公告没有伪造的原文详情链接；只有采集到的真实公告链接会显示准确的源站详情页。
- 采集连接器当前支持标准 RSS / Atom Feed；不支持 RSS/Atom 的网站需要单独开发并核验来源适配器。只有经人工核验并启用的平台来源可执行采集任务。
- 添加来源前需确认该公开来源允许的访问方式及访问频率。示例来源为占位项，不会抓取真实数据。
- 会员登录使用本地密码哈希和会话 Cookie；会员状态停用或到期后无法继续查看会员专属原文链接。管理接口限制在部署电脑本机；平台管理页尚未加入生产环境所需的管理员身份、角色权限和 HTTPS。
- 定时采集仅在电脑服务持续运行期间执行。服务监听电脑网络接口以供同一局域网的手机访问；管理 API 会拒绝非本机请求，不会自动修改 Windows 防火墙规则。
- 此版本可在本机实际新增会员、登记平台与 Feed、启动采集任务、检索数据库公告并查看系统审计；还不是可直接公开上线的多用户生产部署。

## 文件

- `index.html`：四平台入口
- `tenders.html`：公开招标信息与详情
- `members.html`：会员管理
- `maintenance.html`：系统维护
- `collection.html`：采集任务、来源与运行状态
- `server.py`：本地 HTTP 服务、SQLite 数据库及 RSS/Atom 入库逻辑
- `app.js`：页面与本地数据库 API 的连接逻辑
